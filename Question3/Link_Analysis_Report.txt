4. Comparison Between Hard Link and Symbolic Link

Observation:

Hard Link:

* Directly references the file data through the file system.
* Closely associated with the original file's inode information.
* Continues to provide access to the file data as long as a valid reference exists.

Symbolic Link:

* Acts as a reference to a file path.
* Maintains separate file information from the original file.
* Depends on the existence of the referenced file path.

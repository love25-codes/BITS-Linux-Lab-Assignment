# BITS Linux Lab Assignment

## Overview

This repository contains the solutions, reports, screenshots, and supporting files for the Linux Lab Assignment. The assignment covers fundamental Linux concepts including environment verification, file permissions, links, file I/O operations, and storage management.

---

## Repository Structure

```text
Linux-Lab-Assignment/
├── Question1/
├── Question2/
├── Question3/
├── Question4/
└── Question5/
```

Each question folder contains:

* Report file (`.txt`)
* Screenshots of command execution and outputs
* Supporting files created during the experiment
* Observations and explanations

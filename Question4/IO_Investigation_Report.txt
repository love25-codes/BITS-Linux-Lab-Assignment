7. How Linux Manages File I/O

Explanation:

Linux manages file input and output using file descriptors. 
Standard input (0), standard output (1), and standard error (2) are assigned descriptor numbers and are used by processes to communicate with files, terminals, and devices. 
Redirection operators allow output and errors to be stored in files instead of being displayed directly on the terminal.
